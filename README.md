# LZUapp

第三方兰州大学工具箱 App（非官方）。

## 功能

- 课表：周视图、自定义课程、静默同步、本地缓存
- 校园卡：余额、付款码、充值、账单、宿舍电费
- 查寝打卡：定位 + 拍照签到，一键签到
- 其他：课程与教师评教、自动填写、批量评教所有课程和老师、成绩查询、邮箱、校园网自动登录

## 批量评教

- 在评教任务列表点击“一键评教所有课程和老师”，覆盖所有进行中的打分任务；在课程列表点击则只处理当前任务。
- 确认后自动填写并直接提交未评课程和合讲教师，跳过已评对象；合讲课程先提交课程评价、刷新状态，再逐个评价教师。
- 沿用单份表单的一键高分规则和默认中文评语。禁止全最高分时，随机将 2 或 3 道计分单选题降为次高档。
- 支持查看已提交/跳过数量和停止后续评价。失败、必答题缺失或不支持的题型会暂停；不会自动重试失败的提交。先刷新核对当前对象，再决定是否重新开始。
- 单份表单的一键填写成功后直接更新选项和评语，不再弹出成功提示，仍需手动提交。

## 构建

```bash
cd kcb-app
./gradlew :app:assembleDebug
```

需要 JDK 17 和 Android SDK（`local.properties` 里配 `sdk.dir`）。高德定位需要在 `kcb-app/local.properties` 配置 `AMAP_API_KEY`，该文件不纳入版本库；公开地图瓦片不需要此配置。
